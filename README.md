## 🚀 How to Run Locally

### Prerequisites
- Node.js 18+
- npm or yarn

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/Sahil98677/Sahil-Sandeep-Mahadik.git

# 2. Navigate to project folder
cd Sahil-Sandeep-Mahadik

# 3. Install dependencies
npm install

# 4. Start local development server
npm run dev
```

The app will be accessible at `http://localhost:3000` (or the port displayed in your terminal).

### Production Build

```bash
npm run build
```

## 🌐 1-Click Deployment Options

### Deploy on Vercel
1. Import this repository into [Vercel](https://vercel.com).
2. Framework Preset: **Vite**.
3. Build Command: `npm run build`.
4. Output Directory: `dist`.
5. Click **Deploy**.

### Deploy on Netlify
1. Connect this repository to [Netlify](https://netlify.com).
2. Build command: `npm run build`.
3. Publish directory: `dist`.
4. Click **Deploy Site**.
